Конфиденциальность JPEGCeiling

Обновлено: 2026-11-10

JPEGCeiling обрабатывает выбранное фото на вашем устройстве. Tidelab не получает ваши фото через JPEGCeiling. Аккаунт не требуется. Между сеансами приложение сохраняет только последние корректные числовые ограничения, без истории фото.

Пока открыт результат, приложение хранит временную копию исходника в файле, а готовый JPEG — в памяти для повторной отправки или сохранения. Рабочее фото и результат удаляются при закрытии результата, выборе другого фото, отмене импорта или подготовки, ошибке импорта или подготовки либо уходе приложения в фон вне системной операции. Изменение пределов с экрана результата удаляет прежний результат, сохраняя выбранное фото для новой подготовки.

Файлы для активного системного выбора, отправки или экспорта доступны до завершения или отмены операции. Отдельный временный файл для отправки или экспорта удаляется по окончании операции. Сама отправка или сохранение не закрывает результат и не удаляет копию исходника. После сбоя остатки временных файлов удаляются при следующем запуске. Явно экспортированные копии остаются в выбранном месте.

Метаданные исходника в результат не копируются. Импорт из iCloud или другого сервиса и отправка через сторонний сервис выполняются этим сервисом по его правилам. Контакт: tidelab.apps@gmail.com.
