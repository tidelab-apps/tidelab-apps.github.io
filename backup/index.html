Tidelab Backup

Encrypted backups in Google Drive

Private tool · not offered to the public

Tidelab Backup keeps an encrypted backup of its owner's computer in the owner's own Google Drive. It runs on a schedule on that computer and makes a new copy every week.

✓

Encrypted before it leaves

The backup is encrypted on the computer before it is uploaded. The Drive holds only encrypted data, with a password that never leaves the computer.

✓

Only its own files

It uses the Google Drive permission drive.file: it can see only the files and folders it created itself, never anything else in the Drive.

✓

Nothing goes anywhere else

There is no Tidelab server. Files go straight from the owner's computer to the owner's Drive. No analytics, no advertising, no sharing.

✓

Checked, then replaced

After each weekly copy it reads back a part of the data and restores a few files as a test. Only then does it remove the older copy it made before.

How it works

The tool signs in to Google once, with the owner's own Google account, and keeps that sign-in on the computer. Each week it uploads only what changed since the last copy, checks the new copy and then removes the older one. Besides the encrypted backup, it can place copies of the owner's own media files, such as video recordings, in a separate folder that it created in the same Drive, so they can be watched there.

Who can use it

Only its owner, with their own Google account. There is no sign-up and no download: the tool is not offered to other people.
